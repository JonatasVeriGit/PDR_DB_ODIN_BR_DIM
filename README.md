in English

DB_ODIN_BR - Dimensions: A repository responsible for version-controlling objects promoted to production in Snowflake.

Database: DB_ODIN_BR

Deployment role: AZ-SF-BI-BR-DEPLOYER

Structure: 
• dimensions: dimension tables (mapping/lookup tables) 
• views: views used by the business 
• tables: analytical tables 
• releases: deployment documentation 
• rollback: rollback scripts
